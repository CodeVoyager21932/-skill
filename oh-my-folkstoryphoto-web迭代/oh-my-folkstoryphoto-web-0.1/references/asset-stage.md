# 固定资产阶段：先把身份和空间做真

资产阶段只做一件事：为正式 Frame 提供稳定、干净、可复用的现实身份、空间和关键物件参考。

它不承担剧情推进，不重演分镜，不生成正式 Frame，不制作项目总览图。

固定边界：

`STORYBOARD_LOCK(N) → ASSET_BUILD → ASSET_LOCK → GENERATE`

## 1. 固定资产队列必须从分镜交接直接传下来

正式分镜提交时就应同时展示 `FIXED_ASSET_HANDOFF`。用户确认分镜后，这份清单直接成为 `ASSET_BUILD` 的初始队列；**不要到资产阶段才重新从零推断“要做什么资产”**。这样可以保证 Storyboard → Asset 的交接不丢人物、空间或核心道具。

资产 handoff 只包含真正需要长期连续的对象：

- 主要人物与重要配角；
- 反复出现、结构必须稳定的重要场景；
- 核心证据、复杂物件、反复近拍的道具；
- 反复出现且需要稳定识别的神祇、鬼怪、虚构生物或异常实体；
- 反复出现的高风险特殊状态，例如固定特殊妆容、受伤状态、特殊服装。

一次性路人、小杯子、小杂物不必资产化。

分镜提交时展示格式只需要类似：

```text
FIXED_ASSET_HANDOFF
A-P01｜主角｜身份/年龄/体型/固定衣着
A-P02｜重要配角｜身份/固定外观
A-S01｜重要场景｜空间结构/固定设备/使用痕迹
A-R01｜核心物件｜结构/材料/关键特征
```

用户确认后，执行顺序就是 `A-P01 → A-P02 → A-S01 → A-R01`。Asset ID 不要在交接后重新编号。

它只是文字执行顺序，**不是要生成的一张资产总表**，也不需要 Required/DONE 计数系统。不要做逐帧 Fxx 映射。

## 2. 下一步必须具体到一个 Asset ID

进入 `ASSET_BUILD` 后，每次只允许当前队列头部的一个资产生成动作。

例如：

```text
STATE: ASSET_BUILD
NEXT_TOOL_ACTION: GENERATE A-P01
FORMAL_FRAME: FORBIDDEN
```

生成完成后立即看实际图：

- 合格：从队列移除 A-P01，下一步变成 A-P02；
- 不合格：仍然是 A-P01，覆盖同一 ID 重做；
- 队列清空：进入 `ASSET_LOCK`。

如果平台因为单轮工具/图片限制停止，下一轮继续执行当前 `NEXT_TOOL_ACTION`，不得重新规划、不得询问用户先做哪个资产、不得跳到 F01。

### 2.5 ASSET_PROMPT_COMPILER｜Handoff 很短，执行 Prompt 不能因此失真

`FIXED_ASSET_HANDOFF` 只回答“要固定什么”，**不能直接当生成 Prompt**。每次生成当前 `A-*` 前，内部把它展开成一个紧凑的 `ASSET_EXECUTION_SPEC`，只写真正影响下游稳定性的正向锚点。

按资产类型最低覆盖：

- **人物**：身份/年龄感、体型与身高感、脸和头发中少量高辨识锚点、真实皮肤状态、固定服装的版型/材料/颜色与穿着方式、反复出现时重要的鞋/包/小物，以及普通自然姿态和合理现场光。不要靠“普通中国女性 / 真实感”让模型自行决定整张脸和衣服；
- **场景**：空间真实用途、出入口/墙/窗/楼梯等主要拓扑，反复会入镜的固定家具/设备位置，关键材料与年代感，生活/工作使用痕迹，主要实际光源，以及最有用的真实观察方向。只锁后续需要保持的结构，不写完整建筑说明书；
- **关键物件/证据**：现实尺度、材料、整体形状/构造、2–4 个高辨识特征、磨损/损坏/污迹、当前功能或特殊状态；核心关系对象还要继承对应 Mechanism Lock；
- **异常实体**：稳定可辨认轮廓/比例/材料或显现方式、与环境接触/遮挡/受光方式，以及不能漂移的识别锚点。

Prompt 仍以正向描述为主。当前资产若特别容易被模型画错，可在末尾加**一个短的定向负面 guard**，只挡高风险误差，例如“不是棚拍角色设定 / 不出现第二个人 / 不把平面剪纸做成立体动物”。不要复制通用长 negative list。

生成前问：**这份文字如果交给一个没看过项目的图像模型，它会不会在脸、衣服、空间结构、材料、尺度或对象形态上拥有足以影响后续连续性的大片自由发挥？** 如果会，说明还不够具体；补关键锚点，不补无关装饰。

## 3. 一个资产只服务一个资产 ID

硬规则：

> **1 个 Asset ID = 1 个独立资产生成任务 = 1 张只服务这个 Asset ID 的图片**

禁止：

- A01–A20 项目资产总览；
- 人物 + 场景 + 道具混合大板；
- 资产 + 分镜混合；
- 先生成总览，再裁切/提取其中一格当资产；
- 从失败的漫画/概念图里抠出人物继续做 reference。

如果资产图混入第二个人物、第二场景、其他资产格、标题标签、项目 UI 或大总览，整张失败；**不得裁切抢救**，从干净输入重做当前 ID。

## 4. 人物资产：先是现实人物，再是连续性参考

每个人物独立。

优先生成：

> **现实中的这个人，在普通或题材合理环境里留下的一张中景/半身身份参考照片。**

要求：

- 真实年龄、皮肤、头发/胡须、体型、普通姿态；
- 固定服装有真实织物、褶皱、磨损和穿着关系；
- 现场光成立，背景仍可读；
- 不做英雄姿势、海报、棚拍、角色设定、纯色概念背景。

### 三视图不是默认强制

如果侧面/背面连续性确实高风险，可以给同一人物补三视图或补充角度；仍只能是同一个人，并保持现实人物参考摄影感。

如果三视图开始像漫画 turnaround、游戏角色设定或概念 sheet，宁可退回单张自然身份照，不为了“锁得更全”牺牲真实感。

关键妆容、受伤状态、固定特殊服装如果反复出现，可另建独立状态资产；不要做通用表情包。

## 5. 场景资产：一个空间一张图

每个重要空间独立生成。

场景资产锁：

- 出入口与空间结构；
- 固定家具/设备；
- 真实材料；
- 使用、磨损、修补、污迹和堆放；
- 主要现场光源；
- 人实际能到达/观察的位置。

同一个空间有必要时可以表现 2–4 个方向，但不能混入第二场景。若多视角导致“建筑概念板”感，改成一张最有用的现实空间照片，并在正式帧靠上一帧维持连续。

## 6. 道具和异常实体

普通关键道具少时可以同类合并；核心证据、结构复杂或反复近拍的物件单独生成。

反复出现的非人异常实体可使用 `A-E##`，但只锁：

- 可辨认结构；
- 现实材料/重量/接触；
- 或非实体时相机可记录的稳定显现规律。

不要锁“发光描边、魔法烟雾、概念艺术能量效果”作为默认身份。

## 6.5 核心机制资产：先判断“物理同源”还是“结构映射”

Mechanism Lock 涉及多个对象时，**不要默认都走母版派生**。先判断关系本质。

### A. `SOURCE_DERIVATION`｜确实来自同一物理来源

只在两个或多个对象确实来自同一件物、同一原件、同一局部，或属于同一对象的前后状态时使用。此时不要把两端各自从文字重新生成。

优先建立一个**单一母版资产**，再从该母版派生必要状态或匹配局部：

```text
A-R01｜<核心母版对象>｜锁原始结构、材料、纹样/特征与尺度
A-R01-D01｜<同源派生状态>｜必须直接从 A-R01 的对应区域/结构派生
A-R01-P01｜<同源匹配局部>｜必须保留与母版可验证的共同边缘、纹样、结构或材质特征
```

每个 ID 仍然是一张独立资产图，遵守“一资产一图”；派生资产必须使用已通过的母版作为直接来源。工具支持编辑 / 蒙版时优先在母版上做局部编辑；不支持时也必须引用同一母版并锁定具体区域或结构。

这不等于允许从项目资产总板裁格。禁止裁总表仍然有效；允许的是从一张已经通过的**单对象母版资产**做同源局部派生。

### B. `RELATION_REFERENCE`｜不同对象只共享抽象结构/规律

如果两个载体不是同一物理来源，只是剧情要求它们共享某种**几何、拓扑、比例、排列、方向或空间映射**，不要把其中一张图片当另一张的母版，也不要通过贴图、换材质把“同一张形状”机械复制过去。

Mechanism Lock 本身就是关系参考，至少写清：

```text
M1 [RELATION_REFERENCE]
必须保持：<关键拓扑 / 转折顺序 / 比例 / 相对位置 / 排列关系>
允许变化：<载体材质、厚度、局部噪声、形成痕迹、光照、表面细节>
```

然后各载体分别建立自己的现实资产，例如：

```text
A-R01｜<载体 A>｜独立现实资产；遵守 M1
A-R02｜<载体 B>｜独立现实资产；遵守 M1
```

两者可以“让观众认出同一种结构”，但必须仍像各自真实形成的东西：裂纹要像裂纹形成，建筑轮廓要像建筑形成，液体边界要像液体流动。**相似的是关系，不是贴图、材质和局部纹理。**

Mechanism Lock 中锁定的材质身份、尺度身份、物理同源 / 结构映射和状态连续都必须进入资产与后续 Frame；不能为了画面更醒目而擅自更换材料、放大对象、重置状态，或把抽象对应误做成物理同源。


## 7. 风格化资料图：只在理解阶段使用，不直接灌进现实资产

如果原始资料是画像、壁画、插画、木刻、漫画、游戏设定或概念图：

1. 先看图并提取文字识别锚点；
2. 不继承原图纸张、线条、笔触、色调、阴影、构图和艺术风格；
3. 默认不把原始风格化资料图继续作为资产生成的图像 reference；
4. 用文字锚点重新生成“如果这个人/物/空间真实存在，被普通光线和真实相机记录会是什么样”的身份资产；
5. 现实资产通过后，正式 Frame 只继续使用现实资产 + 必要上一正式 Frame，不重新引入原始风格图。

如果用户明确要求保留某个复杂纹样/造型，保留的是**纹样/造型信息**，不是它原来的绘画媒介。

## 8. 资产阶段的失败门

出现任一项，当前资产失败重做：

- 漫画、插画、油画、游戏概念设计、角色海报；
- 人脸雕塑化、明星化、磨皮；
- 场景像美术设定而不像真实被使用的地点；
- 多资产混图；
- 从总览图裁出来的残片；
- 不存在对象仍明显继承原资料的画风；
- 人物定装像“角色设计”，不是“现实身份照片”。

失败图不得继续作为下游 reference。

## 9. 资产锁完成标准

只有队列中每一个资产都实际生成且通过检查，才进入：

```text
STATE: ASSET_LOCK
NEXT_TOOL_ACTION: GENERATE FORMAL BATCH FROM F01
```

不新增用户审批门，不再生成资产汇总大图。
