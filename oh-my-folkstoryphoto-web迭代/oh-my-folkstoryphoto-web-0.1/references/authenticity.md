# 视觉真实性：像一段真实拍摄经历，不像一套被导演好的剧照

目标不是把每张做得更精致，而是让观众相信：这个人真的在这里生活/工作/赶路/出事，这些图片是在过程中留下来的。

## 0. 真实性要在分镜前锁“现实底盘”，但绝不锁统一美术风格

故事确认后、正式切分镜前，先建立一个极短 `REALITY_BASELINE`。它只回答：这个世界现实里如何被使用、真实光从哪里来、不同拍摄处境会怎样影响照片。

好的 Baseline 会说明：地点真实承担什么功能、主要现场光从哪里来、环境如何被使用，以及不同拍摄处境会怎样改变记录结果。光线充足且摄影者有准备时可以正常清楚；临时发现、移动、低照、恶劣天气或设备受限时才可能出现裁切、反光、失焦、噪点或模糊。

坏的 Baseline 会把整篇预设成同一种色调、天气、灯光、构图或“高级纪实风格”。**统一摄影套餐本身就是失败。**

随后在 Storyboard 的每个 Frame 里，把当前处境自然造成的拍摄结果提前决定。真实感不是降低画质，也不是增加脏乱；缺陷、遮挡和不稳定只能来自具体现场与拍摄行为，而不是最后为了“更真实”随机添加。

## 1. 先成立“为什么这一秒会有这张图”

现代/证据型画面在内部确认：谁拍、为什么此刻拍、拍摄者在哪/受什么限制、人物是否知道、为什么这张会被保留、设备在当前条件下会留下什么结果。

不要求每次都理性计划。顺手拍、同行者随便拍、突然举起手机、跑动中按到、撤离时急拍、为了留证据靠近拍，都可以成立。关键是**拍摄行为属于当时的人，而不是属于一个知道剧情的导演**。

历史/神话/非现代现场不强行发明手机，但仍要求可达观察位置、人物不表演、空间被真实使用、现场光和物理关系成立。

## 2. 人要像这个身份与处境下的人，不像被选角的主角

连续性不等于每张都看清脸。允许背影、侧脸、半张脸、遮挡、突然回头、运动中失焦；用发型、体型、衣服、鞋、包、随身物和相邻位置继续确认身份。

当脸足够近且设备足以记录时，保留与年龄、职业、生活状态和环境相符的毛孔、细纹/皱纹、肤色不均、眼周疲惫、自然油脂或干燥、胡渣/碎发、嘴唇状态、汗、雨、灰尘等。年轻人不必强塞皱纹，老人也不应被磨成无暇皮肤。

硬失败：无原因磨皮/瓷娃娃皮肤；明星化五官；漂亮补脸；狼狈处境里妆发、皮肤、衣服仍像刚整理过。

## 3. 地方先真实存在，不给主角让路

家、车、街道、工作间、村屋、旅店、舱室、山路先按真实功能存在。允许无关但合理的杯子、袋子、线缆、家具、工具、磨损、修补、污迹、堆放和遮挡留下来；不要把背景清空，也不要让每个物件都解释剧情。

环境不能只是“昏暗、潮湿、破旧”的背景词。暗、窄、湿、冷、风、雨、灰尘、泥水、玻璃、手电、旧灯和设备必须真的改变人物状态、走位、能见度、反光、曝光、对焦或镜头表面。

光只来自现场：窗光、顶灯、路灯、车灯、手电、屏幕、闪光灯、火、阴天、雪地反光等。允许脸暗、灯管过曝、混合色温、暗部压黑。禁止默认轮廓光、电影侧逆光、统一暖冷调色、棚拍补脸、奶油虚化。

## 4. 人物先做事，摄影不负责把剧情讲得最清楚

优先记录刷牙、收拾、开车、递物、写字、看仪表、赶路、等人、进门、回头、躲雨、扶墙、照手电、和旁人说话等真实行为。

不要为了交代角色或线索让人物停下动作、正对镜头、完整展示脸/全身/道具。门框、同行者、座椅、前景、玻璃、黑暗挡住一部分很正常。重要线索可以只被看见到“足够理解”，不必每次都完整无遮挡。

## 5. 整组照片允许有普通图、急拍图和没拍好的图

不要统一成同样清楚、同样锐利、同样曝光正确、同样有风格。

- 正常白天/稳定拍摄可以很清楚；
- 低照度、旧设备、直闪可以噪点重、前亮后暗或白平衡难看；
- 转身、奔跑、车内颠簸、撤离、突然举机可以模糊、裁切、焦点落错；
- 雨雪、潮湿、玻璃、粉尘可以带来反光、雾气、污迹、雨滴；
- 为记录具体物证而拍的近照可以很丑、很直接。

缺陷必须来自当前条件，不要随机撒颗粒、每张都故意做烂。只要观众仍能理解本帧必须知道的事实，合理缺陷就是可信度，不是返修理由。

不要把整组照片统一成一个“高级视觉风格”。世界、人物和状态要连续；摄影品质、色温、清晰度可以随地点、设备和处境自然变化。

## 6. 现实底盘和连接镜头不是废图

可以早给异常钩子，但在完整奇观/强异常夺权前，要让观众看到足够的普通生活、工作、交通、准备、到达和空间经过，使人物真的像从现实里走进去。

过路、上车、下车、进门、沿路、等待、窗外、抵达、环境状态等镜头，如果能防止瞬移、交代时间/天气/位置，或让相册更像一段真实经历，就有价值。不要因为“没有新异常”自动删掉；也不要为了凑真实感机械补大量走路图。

## 7. 固定资产首先要像“现实身份照片”，不是角色设计

人物资产若像棚拍定妆照、时尚肖像、电影海报、漫画角色、游戏设定或精致概念设计，直接失败重做。

优先答案是：**现实中的这个人，在普通或题材合理的环境里留下的一张中景/半身身份参考照片**。现场光、普通姿态、脸不必占满、背景仍可读，皮肤和衣料像现实存在。

同一人物三视图可以在确实需要连续性时补充，但：

- 只能是同一个人；
- 不加标题、边框、道具板、设计稿底纹；
- 每个视图仍应像现实人物参考摄影，而不是角色 turnaround；
- 如果三视图明显把结果推向插画/设定集，退回单张自然身份照，不强求三视图。

正式 Frame 使用资产时，只继承身份/发型/体型/固定服装等必要锚点；不继承资产的光线、皮肤精修、姿势、背景、景深或画面完成度。

## 8. 现实中不存在的对象：资料只给“认得出来”，现实证据重新建立

神祇、鬼怪、传说人物、虚构生物、幻想建筑或器物如果来源是画像、壁画、插画、木刻、漫画、游戏设定或概念图：

### 先在资料理解阶段提取少量识别锚点

例如：

- 人形：年龄感、脸部大体比例、发型/毛发、服饰与装饰结构、关键器物；
- 生物：轮廓、肢体连接、不可替代的附肢或表面结构；
- 建筑/器物：大体结构、纹样、关键构件和功能。

**到这里就停止继承原图媒介。** 纸张、笔触、线稿、绘画阴影、雕塑化脸、游戏质感、海报构图不进入后续身份。

默认不要把风格化原图继续作为现实资产或正式 Frame 的图像 reference。用已经提取的文字锚点重新建立现实对象。

### 再问：如果它真的存在，会留下什么现实证据？

实体型对象要回答：

- 什么材料组成；
- 有没有真实重量、受力、磨损、褶皱、毛发/皮肤/甲壳；
- 怎么接触地面、衣物、雨水、灰尘、现场光；
- 普通相机从真实位置会拍到什么，而不是“现实版概念设计”长什么样。

非实体异常不强行做成怪兽模型，只锁定：

- 相机能稳定记录的轮廓、透光/遮光、反射、曝光或运动特征；
- 是否投影、是否影响周围物体/光线；
- 哪些现实规律保持正常，哪些异常规则被明确违反。

**异常本身可以不现实，但承载它的世界必须现实。**

## 最后只问五件事

1. 这个人像不像这种身份、年龄和处境下的人，而不是演员/角色设计？
2. 这个地方像不像本来就在被生活/工作，而不是为剧情搭出来？
3. 不存在对象是否已经摆脱原始插画媒介，变成现实世界里可被记录的证据？
4. 这一秒的拍摄难度有没有诚实影响画面，而不是摄影机永远处于最佳状态？
5. 整组放在一起像不像一段经历留下来的照片，而不是统一美术指导的一套剧照？
