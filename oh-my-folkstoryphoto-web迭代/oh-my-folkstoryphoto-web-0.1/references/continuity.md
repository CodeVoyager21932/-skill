# 连续性、资产与 Frame 锁

## 1. 两类 ID 不得混淆

正式 Frame 固定为 `F01...FN`；重生成/编辑覆盖原 ID，不新增 `F(N+1)`。

资产统一使用 `A-*`，永远不占正式 Frame 数量。

## 2. 核心资产只锁身份/结构

只生成跨多图真正需要的角色、地点、车辆、关键道具锚点。资产阶段不重演 `F01...FN`。

### 人物资产

- 每个主要人物单独生成，禁止两个角色混在同一张人物资产图里；
- 身份资产可在同一张图中包含该人物正面、侧面、背面/半侧三视图，但只能出现这一个人物；
- 每个人物还应有一张清楚的独立身份参考；若三视图本身已经足够清楚，可由同一资产承担，不重复制作无意义的第二张“漂亮肖像”；
- 只有故事中反复出现、容易漂移的关键状态才另做状态资产，例如特殊妆容、受伤后状态、固定特殊服装或关键克制表情；不要做通用表情包；
- 与人物强绑定的小物件可以随人物资产出现；
- 不用摄影棚、角色海报、时尚人像或英雄全身照；资产若磨皮、明星化、完美补光，先重做再锁；
- 正式图只继承身份、年龄、体型、发型和固定衣着，不继承资产的光线、皮肤精修、景深、姿势和背景风格。

连续性**不要求每帧脸都清楚**。背影、侧脸、遮挡、运动模糊时，可用体型、头发、衣服、鞋、包、道具和相邻 Frame 位置继续确认身份。

### 场景资产

- 每个重要场景独立一张资产图；
- 同一图可展示该同一个空间的 2–4 个视角，但不得混入第二个场景；
- 锁空间结构、出入口、固定家具/设备、材质与使用痕迹、主要现场光源和真实可达机位；
- 多个空间结构独立、反复出现的重要地点必须分别建立场景资产；不能为了省资产混成一个总场景板。

### 道具资产

- 普通关键道具少时可做一张独立道具板；
- 核心证据、复杂结构或反复近拍的物件必须单独生成；
- 资产图可以是同类物件板，但正式 Frame 永远不能继承这种多格排版。

正式 Prompt 不要重复整份资产规格，只写当前镜头真正需要的稳定锚点。

## 3. 同场景参考

正式 `Fi` 优先参考 `F(i-1)`；必要时再加一个 A-* 资产。通常不要同时塞很多参考。

上一帧负责位置、动作、湿脏破损、道具和环境状态；人物资产负责身份，不负责“把脸变漂亮”。

## 4. 动作、状态与叙述接力

相邻帧先查**视觉状态**：人物位置/朝向、手里物品、衣服湿脏破损、伤势、门/车辆/工具状态、新地点入口。不要瞬移，不要重复首次发现。

再查**叙述状态**：上一帧字幕里人物在哪里、醒/睡、知道什么、准备做什么；下一帧是否突然出现在另一处、另一个人物突然参与、或已经知道了尚未传递的信息。若图片为了节奏省略的只是普通连接动作，用下一帧/上一帧字幕补最小桥接；若需要新增重要动机、决定或因果才能接上，回 Story / Storyboard 修，不拿字幕伪造连续性。

## 5. 动态环境状态梯度

潮水、雨、火、雪、夜色、烟尘、塌方、异常扩张等内部保持单向状态变化，禁止无解释回退。

## 6. 局部返修接缝

返修某 Frame/区间时，同时检查前 2 张和后 3–5 张或到稳定锚点。返修只替换原 Frame ID；除非用户重新批准新 N，否则永远不增加正式图。

## 7. 核心机制关系属于最高优先级连续性

如果题眼依赖对象之间的精确关系，连续性优先级高于“人物每张都更好看”。必须锁住：

- **物理同源**：确实来自同一原件、同一局部或同一对象状态时，来源、边缘、纹样、损伤等要能互相验证；返修时回看对应母版与派生资产；
- **结构映射**：不同对象只共享几何、拓扑、比例、排列或空间关系时，关键结构必须可辨认一致，但各载体仍保持自己的材质、形成逻辑和局部随机性，禁止出现“同一贴图换材质”的复制感；
- **材质身份**：已经建立的纸、布、金属、生物组织、液体、光学显现等不得为了视觉冲击无理由换成另一种存在形态；
- **尺度身份**：同一对象的现实尺寸不得无理由变化，除非故事明确发生尺度变化或此前只是距离/认知误判；
- **状态连续**：已经发生的损坏、受伤、湿脏、开关、位置、缺失或其他可见状态不得无解释回退；
- **关系可读**：关键兑现帧要让观众实际看见“为什么这两个对象/状态属于同一关系”，不能只靠字幕宣布。

返修核心机制 Frame 时，不只检查前后人物位置：`SOURCE_DERIVATION` 回看母版与派生资产；`RELATION_REFERENCE` 回看对应 Mechanism Lock 的关系规格和所有相关载体，确认“关系一致”没有退化成“图片复制”。修复只覆盖原 Frame ID。
