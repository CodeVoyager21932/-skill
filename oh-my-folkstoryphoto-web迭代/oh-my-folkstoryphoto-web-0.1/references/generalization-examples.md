# 普适判断示例：只学决策，不迁移题材

这些案例只用于解释**什么时候启用某条规则、什么时候不要启用**。

**禁止把案例中的人物、物件、场景、异常机制、拍摄瑕疵、情绪类型或视觉风格迁移到无关新作品。** 新作品必须从自己的故事、现实环境和拍摄处境重新判断。


## 先判断：普通连续性够不够

以下情况通常只需要 Asset + Continuity，不需要 Mechanism Lock：
- 同一个人物保持同一张脸、体型和固定服装；
- 同一车辆、设备、普通道具前后保持身份一致；
- 场景位置、天气、伤势、设备开关等按剧情正常延续。

只有当**对象之间的精确关系本身就是观看价值或理解条件**，例如物理同源、精确互补、几何/拓扑映射或同一对象的派生状态，才考虑 Mechanism Lock。

## A. 精确视觉关系型：启用 Mechanism Lock

例：一张旧档案照片被撕成两部分，后续故事价值依赖两半能否证明来自同一张原件。

可锁：
- 材质身份：两半始终是同一种旧相纸；
- 来源/映射：撕裂边缘、图像内容和污损可以互相验证；
- 尺度身份：两半尺寸前后一致；
- 状态连续：被撕开后不能下一帧自动恢复完整。

资产上使用“完整照片母版 → 同源两半派生”。这里的重点是**共享来源**，不是“所有故事都要做碎片/缺口”。

### A2. 抽象结构映射型：启用 `RELATION_REFERENCE`，但不做图片母版派生

例：一条关键曲线先出现在数据图上，后续又分别出现在城市轮廓和墙面裂纹中；故事价值依赖观众认出“它们是同一种结构”，但三者显然不是同一个物体。

可锁：
- `M1 [RELATION_REFERENCE]`：保留关键转折顺序、相对峰谷、整体方向和主要比例；
- 允许变化：线条厚度、局部抖动、材质、形成痕迹、光照、表面噪声。

资产上应让数据图、城市和墙面分别成为自己的现实载体；它们共同遵守 M1，但**不能从同一张曲线图片换材质贴过去**。观众应该认出结构相似，同时仍相信“楼就是楼、裂纹就是裂纹”。

**本例只说明：当一个已锁故事确实依赖抽象结构映射时，怎样稳定执行 `RELATION_REFERENCE`。它不代表推荐的题眼、剧情模式或观看价值范例。**

## B. 探险 / 奇观型：通常不需要 Mechanism Lock

例：人物从现实环境进入一个巨大未知空间，观看价值来自逐步到达、空间尺度和最终看清。

更重要的是：
- Reality Baseline 锁空间功能、现场光、进入方式与真实尺度参照；
- Storyboard 把图数花在“接近 → 进入 → 第一次看清 → 尺度兑现”；
- `MECHANISM_LOCK: NONE` 完全正常。

不要为了显得严谨，额外发明精确机关、碎片映射或证据规则。

## C. 救援 / 行动型：真实性来自任务条件，不来自故意做旧

例：恶劣天气中的现实救援。

Storyboard 可根据实际处境让移动中的记录出现晃动、雨水或能见度问题；但准备阶段、固定机位或光线足够时可以正常清楚。

重点是人物任务、设备状态、距离、天气和行动结果连续。不要把“真实”理解成每张都脏、暗、糊、歪。

## D. 人物 / 情感型：慢推进也可以没有异常

例：一个人物等待多年后第一次确认某个重要的人或结果。

值得展开的可能是：看到 → 不敢确认 → 靠近/核对 → 对方反应 → 人物选择。

这里的慢推进来自**人物意识、关系和动作阶段变化**，不是异常证据升级。通常不需要 Mechanism Lock，也不需要为了“后劲”强制反转。

## 使用结论

- 普适规则负责：看懂、兑现、图数分配、真实观察位置、现实拍摄条件、资产连续、Frame 锁。
- 条件规则负责：只有核心回报依赖精确视觉关系时才启用 Mechanism Lock；物理同源才用母版派生，抽象结构映射则用 `RELATION_REFERENCE` 并让各载体独立现实化。
- 例子只帮助理解边界，不是新作品的默认素材库。
