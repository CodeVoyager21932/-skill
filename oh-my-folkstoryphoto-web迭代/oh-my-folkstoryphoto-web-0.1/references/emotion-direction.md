# 最终感受：知道作品最后落在哪里，但不写情绪公式

情绪不是一级结构，也不负责证明故事好看；每个正式故事在提交前只需要知道，观众看完主要留下什么感受。

可以是不安、惊恐、震撼、敬畏、激动、悲凉、温暖、荒诞、爽、后怕等。不要把“看不懂、太隐晦、需要解释作者想表达什么”当成后劲。

## 使用方法

1. 先确认事件本身值得看，再选最自然的主感受。
2. 不写完整情绪曲线，不新增流程门。
3. 让最终感受来自具体发生的事：距离、尺度、动作、损坏、等待、人物选择、行动结果、关系变化、世界确认。
4. 最终回报不等于强制反转；终于看见、终于做到、主动走进去、付出代价、救下某人、完成选择、确认更大的事实都可以。
5. 不把情绪形容词直接塞给图像模型；画面仍然由现实可见事实和拍摄处境产生。

如果为了强化感受必须新增主题、创伤、回忆、牺牲或关系戏，先判断这些是否真的属于题目，不默认添加。
