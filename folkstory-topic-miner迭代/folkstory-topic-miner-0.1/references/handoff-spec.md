# Topic → Production Handoff

Handoff 只传递 Production 必须保真的题目核心和创作空间，不传递半成品剧本。

## 固定格式

- **标题（兼容旧字段：工作标题）**：面向观众的进入标题。标题与一句话题目分开；不要求把深层机制或正式结局写进标题。
- **一句话题目**：站稳第一层人物 / 处境 / 异常事件即可。不要为了证明脑洞，把完整运行机制、所有后果和正式结局一次讲完。
- **主角 / 最低必要背景**：只写理解题目需要的信息。
- **核心异常 / 主要问题**：写第一层真正发生的异常；若深层机制尚未确定，不提前补规则百科。
- **创新锚点 / INNOVATION_ANCHOR**：写这个题最需要 Production 保住的具体观看身份。可以是异常行为、人物关系、证据方式、现实处境、视觉关系或终点；不要求是新物理机制。它的作用是防止 Production 二次“加创意”把原题改掉。
- **核心观看欲望（第一层观看问题）**：观众第一时间最想亲眼确认什么。
- **后续观看牵引（兼容旧字段：下一层观看问题）**：核心异常 / 承诺已经被确认后，观众为什么仍然想继续看。可以来自持续接近或进入、威胁逼近、异常产生具体后果、对象 / 关系被看懂更深一层、空间或尺度真正打开、人物选择、具体真相、核心兑现，或自然出现新的观看问题。持续接近必须带来题目尚未给出的新价值；若后续主要只剩“继续理解同一机制还能怎么运作”，明确标记风险。
- **最值钱的视觉内容**：最不能被文字替代的单个对象、证据、空间、行为、变化或结果。
- **值得展开的视觉机会**：给 2–4 个**无顺序**候选，只写哪些东西值得让观众亲眼多看一会儿，不写 Frame、不写图数、不写角度。Production 可以删、改、重排。
- **核心兑现潜力**：这个题最值得抵达的方向或层级。优先能落成具体对象、事件、变化、行动结果或事实确认；如果主要依赖一句抽象含义才能成立，明确标记风险。它不是正式结局，也不用提前把整套世界机制闭环。
- **序列耐久来源**：为什么核心异常坐实以后，后续图片仍然有不同性质的价值。物理路径、距离缩短、“终于走到里面”或“同一机制还有更多用法”都不能单独充当耐久来源；除非因此出现新的结构、行为、后果、功能、关系、危险、选择、真相或尺度重定义。
- **题材原生后劲**：写最自然的一种主要感受，并补一句这种感受最应该从题目的什么具体东西产生。例如震撼来自世界真正打开，恐惧来自威胁真的逼近，悲凉来自人物完成某个选择。
- **主要失败风险**：只写一个最可能让题变差的方向，例如“变成同类证据堆叠”“越写越像规则说明”“人物一直替观众测试机制”“核心快感其实在语音而不在图里”“复杂关系需要观众自己拼才看懂”“最终兑现只能靠隐含解释成立”“题目已经把最值钱的最终画面说完”。
- **来源边界**：事实 / 传统 / 现代参考 / 新增虚构。

## 兼容规则

- 旧 Handoff 只有 `工作标题` 时继续接受，把它视为当前标题；不要求为了字段升级重写已锁项目。
- 新项目优先使用 `后续观看牵引`。
- 旧项目只有 `下一层观看问题` 时，Production 和 Auditor 继续接受；把它理解为后续观看牵引的一种形式，不要求为了格式升级重写已锁题目。
- 不因为旧 Handoff 没有新字段就判定缺失，只要原内容能说明核心成立后为什么仍值得看。
- 旧项目没有 `INNOVATION_ANCHOR` 时，Production 从已锁题眼里内部提取最值得保护的一层即可，不要求回 Topic 补格式。

## 可选字段

只有天然成立时才补：

- **参与欲望**：观众确实想跟人物亲自做什么；
- **职业 / 技能价值**：人物能力确实会改变事件；
- **特殊媒介价值**：旧照片、监控、工作记录等本身就是故事核心。

## 不传递

- Topic 内部三步事件试跑；
- 正式剧情顺序；
- 正式结局；
- 正式图数；
- 快慢分镜分配；
- 第一 / 第三视角、具体观察位置或摄影者；
- 分镜；
- Prompt；
- 完整规则表；
- 主题寓意；
- 强制的玩法清单。

边界原则：

> Topic 负责告诉 Production **什么值得做、最该保住什么、核心成立以后为什么仍值得看、这个题最值得抵达到哪里**；Production 先把这些已有价值讲好，再决定哪里需要局部增强，不自动为作品追加第二个“主创新”。
