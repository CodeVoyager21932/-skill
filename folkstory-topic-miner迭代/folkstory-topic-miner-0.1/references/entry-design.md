# Entry Design｜先让观众愿意进门

这份文件只解决 Topic 的最前一层：第一段是否已经形成真实观看欲望。它在三步事件试跑、Strong Seed Deepening、Payoff Ceiling 之前使用。

目标：**先证明观众愿意继续，再讨论这颗种子后面能长多高。** 清楚、奇怪、好画都可以加分，但不能替代第一层观看债务。

## 1. Story Entry 与 Designed Anomaly 分开看

一个入口可以很怪，也可以暂时没有超自然异常。真正要确认的是：

> **当前已经发生的事情，是否让观众自然需要下一步？**

强入口常见来源包括：

- 人正在失去原本拥有的东西，或现实处境开始受损；
- 一个关系、失踪、等待、返乡、寻找、调查等未完成事件重新启动；
- 一个威胁或陌生存在主动靠近、跟随、寻找、进入；
- 动物、人群、机器或物件表现出明显目的，观众自然想知道它在做什么；
- 一个现实任务突然无法照旧完成；
- 一个共知未知、传说地点或具体发现出现可信入口，观众已经知道自己想确认什么。

不要把“必须有人受伤 / 失踪 / 有家庭关系”写成统一模板。狗在村口持续垒墙也可以是强入口，因为它的行为有明显目的性；单纯悬在空中的奇观则要额外证明观众为什么需要继续。

## 2. BLIND ENTRY GATE｜完全遮住后续再判入口

每个有希望的粗种子先只保留**故事当前最早已经发生的事实**。暂时遮住：

- 后续解释；
- 第二层机制；
- “这题好看在哪”；
- 最值钱的视觉内容；
- Strong Seed Deepening 分支；
- Payoff Ceiling；
- 最终大景 / 世界观；
- benchmark 对它的评价。

只问四个问题：

1. **Clarity**：我现在知道发生了什么吗？
2. **Entry pull**：我现在为什么需要下一步？
3. **Entry debt**：已经欠下哪一件未完成的事情？
4. **Self-sufficiency**：如果必须说“后面会发现……”才能证明它有趣，真正的钩子是不是来晚了？

内部冻结：

`ENTRY_PULL = STRONG / MEDIUM / WEAK`

并写一句：

`ENTRY_DEBT = ...`

后续 Deepening、Payoff、视觉上限和 benchmark 不得反向把 `ENTRY_PULL` 调高。

## 3. LATE_HOOK｜真正有力的事情是不是发生得太晚

如果第一层本身只有“奇怪”，直到第二层出现损失、意图、威胁、关系、具体事实或现实后果以后才真正想看，标记：

`LATE_HOOK = YES`

先尝试一次**入口重定位**：把最早那件真正制造观看债务的具体事件向前移动，同时保留后续最贵的 reveal。

例如：

- 弱入口：发现界碑移动；后来才发现界碑外的土地会快速荒废。
- 可尝试的重定位：先出现一块刚耕作的土地突然像荒废多年，同时界碑位置也改变。

入口重定位只做一次。若前移以后仍主要依赖“作者解释为什么这很重要”，降低优先级或淘汰。不要为了修入口把正式结局或深层机制直接写进开头。

## 4. 不让后段潜力替入口洗分

`PAYOFF_CEILING`、大尺度世界、漂亮终局、可拍画面都属于后续价值。

硬保护：

> **ENTRY_PULL 在 Blind Entry Gate 完成后冻结。后续价值可以证明“留下来以后值”，不能证明“观众一开始就会留下来”。**

高档候选若 `ENTRY_PULL = WEAK`，不能因为后段很强直接判为 high-bar contender。`MEDIUM` 可以继续深挖，但要如实保留入口风险。

## 5. 第一轮发散先找“正在进行的事情”

生成粗种子时优先问：

> **今天发生了什么，让一个原本正常进行中的人、关系、任务、地点或事情突然不能照旧继续？**

异常可以随后进入。不要把“第一张必须立刻出现一个违反物理规律的对象”当成默认要求。

熟悉入口合法。返乡、失踪、工作、等待、调查、寻找、照看牲畜、家庭关系、旅途遭遇都可以使用；真正要避免的是入口、核心异常、推进和终点整条一起换皮。

## 6. POOL_ENTRY_ENGINE_AUDIT｜六个题为什么都让人进门

最终池形成后，在故事发动机去重之前，先把标题和第一层入口里的专名删掉，只问：

> **观众为什么现在需要下一步？**

常见入口发动方式包括：

- 人的现实损失 / 风险；
- 人际关系或未完成命运；
- 明确任务 / 寻找 / 调查；
- 主动威胁持续靠近；
- 异常行为表现出明确目的；
- 共知未知 / 传奇目的地；
- 具体发现直接制造存在性问题；
- 单纯不可能物理现象。

不设配额，也不禁止“物理异常”这一类。若多数候选都只能压成“一个无生命对象突然违反物理规律，所以看看后面还有什么”，标记 `POOL_ENTRY_RISK`，重新发散一部分入口。

## 7. 入口与图片原生性各自守门

图片原生仍然重要。强入口最好也能通过图片快速建立，但不要让“特别好画”替代“特别想跟”。

- 视觉很强 + 入口弱：保留为视觉种子，不自动进入强种子名单；
- 入口强 + 画面暂时普通：先看后续是否能产生足够图片价值；
- 两者都强：优先深挖。

这套入口门只负责判断“愿不愿意进门”，不取代三步事件试跑、Story Debt、Payoff Ceiling 和标题设计。
