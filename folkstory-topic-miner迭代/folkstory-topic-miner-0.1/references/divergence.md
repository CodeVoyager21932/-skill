# Creative Divergence｜只在真正弱的地方发散

这份文件只在候选确实平、旧、同质，或一个强种子的某一层已经被明确诊断为弱点时读取。

目标：**保护已经成立的入口与核心观看价值，只对失速层做发散。** 发散不是默认动作，也不是“独具创意”任务的固定配额。

## 1. 先做 PRESERVE LIST

发散前先写 1–3 个必须保住的东西，例如：

- 已经很强的第一笔观看债；
- 一个具体、可记住的异常行为；
- 自然的人物关系 / 现实任务；
- 最值钱的视觉对象；
- 已经成立的简单推进。

再写：

`INNOVATION_FOCUS = 这个题最需要拥有自己身份的那一层。`

后续替代方案不得为了修弱点把这些一起推翻。

## 2. 第一轮先找正在进行的故事

不要从“职业 + 场景 + 新奇物理现象”机械拼题。先问：

> **今天什么事情突然不能照旧继续？**

可以来自失去、工作、等待、失踪、返乡、寻找、旅行、运输、照看、调查、救援、边界跨越、动物 / 人群异常行为、传统线索出现现实证据等。

熟悉入口完全合法。先要求它形成真实观看债务，再考虑创新。

## 3. 三步事件试跑允许成熟 spine

内部只跑：

1. 第一件具体事件；
2. 人物 / 环境 / 异常为什么自然推到下一步；
3. 下一步是否产生新的处境、后果、威胁、距离、理解、选择、空间或兑现。

成熟 spine 可以直接使用，例如：

- 旧事件被今天的新证据重新启动；
- 近身威胁一次次缩短距离；
- 现实任务逐渐进入未知；
- 私人线索驱动寻找一个公共未知；
- 单线调查不断接近一个具体事实。

这些是故事语法，不需要为了原创先拆掉。

危险信号仍然包括：

- 改一个变量 → 看同一规则反馈 → 再改变量；
- 找到对应物 → 再找对应物 → 只证明同一映射；
- 只把已公开对象从远处拍到近处；
- 第三步仍只是解释“这个机制还能这样用”。

## 4. 强 baseline 先停，不自动找“更意外”

如果 baseline 已经：

- 简单但想看；
- 人物继续自然；
- 每一步有事件价值；
- 能抵达具体 payoff；

就保留。

只有第二层明显可预测、陈旧、走不长或回报过轻时，才寻找少量不同方向。

## 5. 真要发散时，只改弱层

可问：

- 下一件具体事情还能是什么；
- 同一个核心怎样真正造成后果；
- 人物是否会做一个自然选择；
- 对象能否被重新理解，而不加新世界；
- 熟悉关系、时间、空间、因果、观察、功能中，哪一层恰好能解决当前问题。

关系创新只是工具。原种子已经锋利时不要再叠第二主机制。

## 6. Benchmark-guided divergence

用户明确要求参考 benchmark 时，可以读取 `benchmark-isolation.md` 的 `TRANSFERABLE_GRAMMAR`，用成熟 spine 帮当前弱点找路。

优先借：入口功能、人物继续理由、中段 story inertia、payoff function。

继续隔离：原人物、原地点、标志物、独特异常、逐段反转链、结局。

benchmark 本身 craft 弱时不因为“是对标”就模仿；novelty 高但故事差时只当灵感刺激。

## 7. 反换皮看整体身份

候选池仍检查：

- 异常怎么工作；
- 人物 / 事件为什么继续；
- 后面靠什么产生新价值。

多个候选若共享同一发动机，重做其中一部分即可。不要为了池内差异把每个题都做成完全不同的叙事物种。

真正危险的是：入口、异常、推进和终点都能被同一现成模板替换，同时没有一个具体 `INNOVATION_FOCUS`。

## 8. 允许冒险，但不奖励复杂

少量怪、狠、浪漫、荒诞、宏大方向仍然合法。只要它真的更好，就可以选。

> **过度保守和过度创新都不是目标；目标是让当前最弱的一层变强。**
