# 严重度与根因

## 0. 竞争力和严重度分开

`BENCHMARK_COMPETITIVENESS` 用于描述 Topic / Story 相对对标的创意竞争力，不属于 P0 / P1 / P2。低于对标中位数本身不自动变成生产错误；只有能指出具体的观看牵引、故事生命力、清晰度、兑现等缺陷时，再按实际影响归层和定级。

## 1. P0｜阻塞级

不修就会改变故事事实、破坏核心观看回报、违反已锁生产合同，或让观众无法正确理解关键事件。

常见 P0：

- 最终图片没有完成该 Frame 唯一核心任务；
- 关键动作对象/方向/位置错误，导致事件变了；
- 核心机制、材质、身份、来源关系或尺度被改写；
- 已确认状态无理由回退，直接制造逻辑矛盾；
- 漏帧、重复 ID、N 错误、把覆盖候选计成新 Frame；
- 关键人物/物件身份漂移到无法视为同一对象；
- 正式单帧生成成拼贴/九宫格；
- 真实摄影是硬要求却输出为明显插画/漫画/概念设计；
- Story / Storyboard 本身无法让核心事件成立，重生图片也救不了。

`P0` 不要求问题“很丑”。一张非常漂亮但讲错故事的图仍然是 P0。

## 2. P1｜重要质量问题

故事仍可理解，但明显损害可信度、观看效率、连续性、情绪或最终完成度。

例如：

- 核心关系勉强可猜但不够清楚；
- 重要证据被遮挡过度但仍能从后文补回来；
- 分镜重复验证、节奏分配不合理；
- 真实感系统性滑向统一电影剧照；
- 人物/场景局部连续性漂移；
- 固定资产交接漏掉高风险重复对象；
- 明显 AI 痕迹破坏沉浸，但没有改变剧情事实；
- 结尾兑现弱，但不是完全没有兑现。

## 3. P2｜可选优化

不修也不影响理解和核心可信度，只是完成度、构图或局部审美可以更好。

不要把 P2 说成“必须返修”。

## 4. 根因归层

### TOPIC
题眼、图像原生性、后续观看牵引或兑现潜力本身不足。

### STORY
事件链、人物行动、重大切换桥接、主观看牵引、关键反转落地、因果或 payoff 出问题。

### STORYBOARD
Frame 分配、动作瞬间、视角、揭示、必要过程、现实记录条件设计错误。

### ASSET
人物/场景/关键物件/现实化实体的固定资产本身错误或污染后续。

### PROMPT_SPEC
Story / Storyboard / 已锁资产要求本来足够清楚，但在编译资产 Prompt 或正式 Frame Prompt 时遗漏了会影响身份、空间、动作、连续状态、关键关系或现实记录的必要锚点，导致图像模型拥有过大的剧情相关自由度。Prompt 已经充分、图片仍没执行出来时才归 `GENERATION`。

### GENERATION
上游要求与执行 Prompt 都足够清楚，但具体图片没有执行出来。

### PIPELINE
N、Frame ID、漏帧/重复、阶段跳跃、错误覆盖、批次状态等生产流程错误。

## 5. 根因优先于传播范围

一个错误可能影响很多帧，但只要来源相同，不要重复算成几十个独立根因。

示例：

- A-P01 一开始就做成游戏角色，F01-F20 都继承：`ASSET → GENERATION`；
- Storyboard 规定角色摸错对象，图片完全照做：`STORYBOARD`；
- Storyboard 写对，但正式 Prompt 只写“人物在厨房看泥爪印”，漏掉关键对象形态/位置/连续状态，图片因此自由发挥：`PROMPT_SPEC`；
- Storyboard 与 Prompt 都写对，图片仍摸错对象：`GENERATION`；
- F27 被生成两次并误当 F28：`PIPELINE`。
